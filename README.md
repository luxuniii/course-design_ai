# 半导体产线智能质量预警系统

## 项目简介

本项目为**制造智能技术课程设计**成果，基于 UCI 公开的半导体制造 SECOM 数据集，构建了一套完整的 B/S 架构工业质量预警系统。系统实现了从原始数据清洗、数据库存储、后端服务开发到前端可视化交互的全链路流程，集成 PCA 高维降维、孤立森林异常检测、随机森林质量预测三大核心算法，可对半导体生产批次进行一键智能分析，提前识别工艺异常与质量风险。

## 环境与依赖

### 环境要求

- Python 3.8 ~ 3.12
- 现代浏览器（Chrome、Edge 等）

### 依赖安装

在项目根目录执行以下命令安装依赖，推荐使用国内镜像源加速：

```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 运行说明

### 第一步：初始化数据库（首次运行执行一次即可）

```
python src/init_db.py
```

执行后会在 `data/` 目录下生成 `quality_system.db` 数据库文件，并导入全部批次与传感器数据。

### 第二步：启动后端服务

```
python src/app.py
```

启动成功后终端显示：

```
==================================================
半导体产线智能质量预警系统 后端服务启动
访问地址：http://127.0.0.1:5000
==================================================
```

### 第三步：访问系统

打开浏览器访问以下地址即可使用：

- 系统首页：`http://127.0.0.1:5000/`
- 批次列表：`http://127.0.0.1:5000/batch/list`
- 批次详情：`http://127.0.0.1:5000/batch/1`

## 系统功能模块

### 1. 数据层

- 基于 UCI SECOM 公开工业数据集，完成缺失值填充、特征筛选、数据集划分（训练集 / 验证集 / 测试集）
- SQLite 关系型数据库存储，设计批次表、传感器数据表、算法结果表三张核心表
- 统一 `db_api` 封装层，所有业务逻辑通过函数调用数据库，避免原生 SQL 冗余

### 2. 后端服务层

- 标准 RESTful API 设计，所有接口统一采用 `code/msg/data` 返回格式
- 页面路由：首页、批次列表、批次详情三类页面路由
- 业务接口：批次查询、传感器数据查询、模型训练、单批次智能分析四大类接口
- 分层架构：路由层 → 算法层 → 数据层，职责清晰，易于扩展

### 3. 智能算法层

表格

| 算法 | 功能说明 |
| --- | --- |
| PCA 降维 | 将 590 维高维传感器特征压缩至二维主成分，实现高维工艺数据可视化 |
| 孤立森林 | 无监督异常检测算法，识别生产过程中的异常工艺模式，输出风险得分与等级 |
| 随机森林 | 监督学习分类模型，基于传感器测量数据提前预判批次最终合格 / 失效 |

### 4. 前端交互层

- **系统首页**：展示服务运行状态，提供功能导航入口
- **批次列表页**：表格化展示全部生产批次，标注质量标签，支持跳转详情
- **批次详情页**：展示批次基本信息与传感器数据，支持一键执行全流程智能分析，分卡片展示三项算法结果

## 数据集说明

本项目使用 UCI 机器学习仓库公开的 **SECOM 半导体制造数据集**：

- 数据来源：UCI Machine Learning Repository
- 样本规模：1567 个生产批次
- 特征维度：590 个传感器测量特征
- 标签分布：合格样本 1463 个，失效样本 104 个
- 场景背景：半导体晶圆制造过程中的在线传感器测量数据与最终质量检测结果

## 注意事项

1. 启动服务前请确保已执行过数据库初始化脚本
2. 开发模式下修改代码后服务会自动重启，页面刷新建议使用 `Ctrl+F5` 强制清除缓存
3. 算法准确率为训练集自评结果，用于课程设计功能演示；若需严谨评估可扩展为测试集验证
