# 数据集来源说明
## 数据集名称
SECOM 半导体制造工艺传感器数据集

## 官方来源链接
https://archive.ics.uci.edu/ml/datasets/SECOM

## 采集场景
半导体晶圆生产线真实工业场景，采集自生产线上的多个工艺传感器，包含温度、压强、气体流量、腔体参数等590路工艺测量信号，标签为对应生产批次的最终质量合格/失效结果。

## 样本规模
- 总生产批次：1567条
- 传感器特征：590维
- 失效样本占比：约6.6%
- 数据特性：存在真实工业缺失值、高维特征、类别不平衡

## 目录文件说明
- `data/raw/secom.data`：原始传感器测量主数据文件
- `data/raw/secom_labels.data`：对应批次质量标签文件
- `data/raw/secom.names`：数据集官方特征说明文件

## 数据使用说明
本数据集为UCI公开工业数据集，仅用于课程设计学习与实验，无商业用途。
