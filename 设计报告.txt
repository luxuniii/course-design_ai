一、课程设计报告：半导体产线智能质量预警系统
摘要
本设计面向半导体制造过程质量管控需求，基于 UCI 公开的 SECOM 半导体生产数据集，构建了一套 B/S 架构的智能质量预警系统。系统采用 Flask 作为后端 Web 框架，SQLite 作为数据存储载体，集成主成分分析（PCA）、孤立森林（Isolation Forest）、随机森林（Random Forest）三种机器学习算法，实现了生产批次数据管理、高维工艺特征降维可视化、工艺异常检测、产品质量提前预测等核心功能。系统分层清晰、交互友好，完整覆盖数据预处理、数据库设计、后端服务开发、前端交互实现全流程，可为半导体制造场景的质量预警提供轻量化的工程化解决方案。
一、项目背景与意义
1.1 行业背景
半导体晶圆制造工艺复杂、工序繁多，生产过程中会产生数百维的传感器测量数据。传统质量管控依赖事后检测，发现缺陷时已造成生产成本浪费。借助机器学习技术对工艺数据进行实时分析，实现质量提前预警，是智能制造领域的重要应用方向。
1.2 问题提出
半导体生产数据具有高维度、非线性、样本不均衡的特点，传统统计过程控制（SPC）方法难以有效挖掘复杂工艺特征与最终质量的关联关系。同时，工业场景需要可视化、可交互的软件系统承载算法能力，而非单纯的离线脚本计算。
1.3 设计目标
构建完整的工业数据处理与存储体系，实现 SECOM 数据集的清洗、划分与结构化存储
集成三类典型工业智能算法，实现高维数据降维、异常检测、质量预测功能
开发 B/S 架构的 Web 应用系统，提供批次管理、一键智能分析、结果可视化的交互能力
遵循工程化开发规范，保证系统可复现、可扩展、易维护
二、需求分析
2.1 功能需求
数据管理功能：支持生产批次信息查询、传感器测量数据查看、数据集划分标识
模型训练功能：支持一键训练三类算法模型，输出模型评估指标
智能分析功能：对单批次执行全流程智能分析，输出降维结果、风险等级、质量预测结果
结果存储功能：所有分析结果存入数据库，支持历史追溯
Web 交互功能：通过浏览器访问系统，页面化展示所有功能与结果
2.2 非功能需求
易用性：界面简洁直观，操作流程清晰，无需专业技术背景即可使用
响应性：单批次分析响应时间控制在 3 秒内，页面加载流畅
可扩展性：采用分层架构，算法模块与业务模块解耦，便于后续扩展算法与功能
可复现性：所有数据处理与模型训练均可通过脚本复现结果
三、系统总体设计
3.1 系统架构
系统采用经典的三层 B/S 架构，自上而下分为表现层、业务逻辑层、数据层：
表现层：基于 HTML+Bootstrap + 原生 JavaScript 开发的 Web 页面，负责数据展示与用户交互
业务逻辑层：基于 Flask 框架构建后端服务，包含路由控制、算法调度、业务逻辑处理
数据层：SQLite 关系型数据库，存储批次信息、传感器数据、算法结果三类核心数据
3.2 功能模块划分
系统分为四大功能模块：
数据预处理模块：完成原始数据清洗、缺失值填充、特征标准化、数据集划分
数据库管理模块：数据表设计、数据入库、统一封装的数据访问接口
智能算法模块：PCA 降维、孤立森林异常检测、随机森林质量预测三个独立算法单元
Web 交互模块：首页导航、批次列表、批次详情与智能分析三个页面单元
3.3 数据库设计
数据库设计三张核心数据表：
批次表（batch）：存储批次 ID、批次编号、最终质量结果、数据集划分类型
传感器数据表（sensor_data）：存储每个批次对应的 590 维传感器测量值
算法结果表（analysis_result）：存储每次智能分析的 PCA 坐标、异常得分、质量预测结果与置信度
四、详细设计与实现
4.1 数据预处理实现
缺失值处理：对缺失率过高的特征进行剔除，剩余缺失值采用中位数填充
特征标准化：对数值型特征执行 Z-score 标准化，消除量纲差异
数据集划分：按照 7:2:1 比例划分为训练集、验证集、测试集，保持正负样本分布一致
4.2 后端服务实现
基于 Flask 框架实现 RESTful 风格的 API 接口，所有接口统一采用code/msg/data格式返回数据。核心接口包括：
批次查询接口：GET /api/batch/list、GET /api/batch/{id}
传感器数据接口：GET /api/batch/{id}/sensor
模型训练接口：POST /api/model/train
智能分析接口：POST /api/model/predict/{id}
4.3 前端页面实现
系统首页：展示系统名称、服务运行状态、功能导航入口
批次列表页：以表格形式展示全部生产批次，标注合格 / 失效状态，支持跳转详情
批次详情页：展示批次基本信息，提供一键智能分析按钮，分卡片展示三项算法结果
五、核心算法设计
5.1 PCA 高维特征降维
主成分分析通过正交变换将高维相关特征转换为低维无关主成分。本系统将 590 维传感器特征压缩至 2 维主成分，实现高维工艺数据的可视化呈现，同时保留主要方差信息，用于后续异常判定与分布观察。
5.2 孤立森林异常检测
孤立森林是无监督异常检测算法，通过随机划分样本空间构建孤立树，异常样本更容易被快速孤立。本系统用训练集拟合孤立森林模型，对输入批次计算异常得分，划分为高、中、低三个风险等级，实现工艺过程的异常识别。
5.3 随机森林质量预测
随机森林是集成学习分类算法，通过多棵决策树投票输出最终分类结果。本系统以传感器特征为输入，最终质量结果为标签训练分类模型，能够在生产过程中提前预判批次合格 / 失效，并输出预测置信度。

7.1 设计总结
